# smart-grievance
=======
# Smart Grievance Redressal & Tracking System for Villages

An end-to-end digital governance platform uniting rural citizens, field technicians, Panchayat officers, and district administrators with AI assistance, voice grievance lodging, proof-of-work tracking, and welfare/ration transparency.

## Project Structure
```
smart-grievance/
├── backend/             # Node.js + Express + TypeScript + MongoDB + Socket.io
├── apps/
│   ├── citizen_flutter/ # Voice-First Rural Citizen Mobile App (Hindi & English)
│   ├── worker_flutter/  # Field Worker Proof of Work & GPS App
│   ├── admin_web/       # District Admin Command Center (React + Vite + TS)
│   └── panchayat_web/   # Panchayat Sachiv Governance Portal (React + Vite + TS)
├── docs/                # Architecture, API, Database, Setup, and Demo walkthrough
├── docker/              # Multi-stage Dockerfile and Docker Compose
└── scripts/             # Start, seed, and test scripts
```
